## Структура проекта

```text
/my_rag_project/
├── saiga-mistral-7b.Q4_K_M.gguf      # скачанная модель
├── prepare_data.py                    # подготовка данных
├── app.py                             # RAG-сервер
├── requirements.txt                   # зависимости
├── /pdfs/                             # ваши PDF
│   ├── document1.pdf
│   └── another_book.pdf
└── /templates/
    └── index.html
```

Поместите все PDF-файлы в папку **pdfs/**.

---

## Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## Подготовка данных

### 1. Запуск процесса индексации

Выполните:

```bash
python prepare_data.py
```

Скрипт:

* извлечёт текст из всех PDF;
* разделит данные на чанки;
* сохранит результат в `processed_chunks.json`.

---

## Запуск RAG‑сервера

Выполните:

```bash
python app.py
```

При первом запуске:

* будет создан и сохранён векторный индекс в папке **faiss_index/**;
* процесс может занять время в зависимости от размера PDF;
* все последующие запуски будут быстрыми.

После загрузки появится сообщение:

```
RAG-пайплайн готов к работе!
```
