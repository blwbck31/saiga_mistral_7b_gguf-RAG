Как всё запустить (финальная инструкция)
Создайте структуру проекта:

text

/my_rag_project/
├── saiga-mistral-7b.Q4_K_M.gguf  (скачанная модель)
├── prepare_data.py
├── app.py
├── requirements.txt
├── /pdfs/
│   ├── document1.pdf
│   └── another_book.pdf
└── /templates/
    └── index.html
Поместите ваши PDF-файлы в папку pdfs.

Установите зависимости:
pip install -r requirements.txt

Подготовьте данные (создайте индекс):

Запустите скрипт: python prepare_data.py
Он извлечет текст из всех ваших PDF, нарежет его на чанки и создаст файл processed_chunks.json.
Запустите RAG-сервер:

Выполните команду: python app.py
При первом запуске он создаст и сохранит векторный индекс в папке faiss_index. Это может занять некоторое время в зависимости от объема ваших PDF. Последующие запуски будут быстрыми.
Дождитесь сообщения "RAG-пайплайн готов к работе!".
Откройте веб-интерфейс:

Откройте в браузере адрес http://127.0.0.1:5000.
Задавайте вопросы по содержимому ваших документов
